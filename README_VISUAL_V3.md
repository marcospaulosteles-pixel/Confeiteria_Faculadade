# Visual V3 — foco em microempreendedora que produz sozinha

Esta versão foi desenhada para uma confeitaria artesanal domiciliar, com produção individual e encomendas de festas.

Principais mudanças:
- linguagem acolhedora sem prometer disponibilidade automática;
- aviso claro de que a agenda/capacidade é confirmada antes da produção;
- atalhos de 25, 50 e 100 unidades para encomendas de festa;
- resumo dinâmico de quantidade e valor estimado;
- reforço de privacidade e ausência de cobrança automática;
- fluxo de 4 etapas: solicitar, confirmar, produzir e retirar/receber;
- dashboard reorganizado para pedidos, custos, estoque, validade e demanda;
- layout responsivo para celular.

Para atualizar o projeto já hospedado, envie o CONTEÚDO desta pasta para a raiz do repositório GitHub, como foi feito na V2.
