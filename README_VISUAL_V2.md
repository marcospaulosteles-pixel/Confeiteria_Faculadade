# Doce Encanto — Visual 2.0

Esta versão mantém o funcionamento do sistema e moderniza a interface pública.

## Atualização no GitHub
Substitua os arquivos do repositório pelos desta versão (mantendo `render.yaml`). O Render fará novo deploy automaticamente.

## Fotos dos produtos
No `/admin/`, edite um Produto e preencha **URL da imagem** com um endereço público HTTPS da foto. Se ficar vazio, o site mostra um ícone de cupcake.

## O que mudou
- hero/banner responsivo;
- cards de produtos;
- layout otimizado para celular;
- formulário redesenhado;
- seção "Como funciona";
- navegação e rodapé profissionais;
- campo opcional de URL de imagem por produto.
